# DocSign — Document Signing Platform

A professional client-facing document signing app built with Next.js, TypeScript, Tailwind CSS, and Convex.

---

## Tech Stack

- **Next.js 14** (App Router)
- **React 18** + **TypeScript**
- **Tailwind CSS** — dark luxury aesthetic with gold accents
- **Convex** — real-time backend database
- **Lucide React** — icons

---

## Features

- Client info collection (name, email, company)
- Document listing with required/optional selection
- Inline document preview (expand/collapse)
- **Freehand signature canvas** (mouse & touch)
- Per-document signing with legal consent checkbox
- Progress tracker across all selected documents
- Submit all signatures to Convex in one mutation
- Downloadable signing receipt (`.txt`)
- Fully responsive (mobile-first)

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Create a Convex project

```bash
npx convex dev
```

This will:
- Prompt you to create/log into a Convex account
- Scaffold the `convex/` directory
- Regenerate `convex/_generated/` with your actual deployment types
- Output your `NEXT_PUBLIC_CONVEX_URL`

### 3. Configure environment

```bash
cp .env.local.example .env.local
# Fill in your NEXT_PUBLIC_CONVEX_URL from the Convex dashboard
```

### 4. Run the dev server

```bash
# Terminal 1 — Next.js
npm run dev

# Terminal 2 — Convex (keep syncing)
npm run convex:dev
```

Open [http://localhost:3000](http://localhost:3000).

## Database Schema

### `submissions`

| Field          | Type     | Description                     |
|----------------|----------|---------------------------------|
| `clientName`   | string   | Full name from form             |
| `clientEmail`  | string   | Email (indexed)                 |
| `clientCompany`| string?  | Optional company name           |
| `submittedAt`  | string   | ISO timestamp                   |
| `status`       | string   | `"complete"`                    |
| `totalDocs`    | number   | Count of signed documents       |

### `signedDocuments`

| Field           | Type          | Description                     |
|-----------------|---------------|---------------------------------|
| `submissionId`  | Id<submissions>| Parent submission               |
| `documentId`    | string        | e.g. `"nda-001"`               |
| `documentTitle` | string        | Human-readable title            |
| `signatureData` | string        | Base64 PNG data URL             |
| `signedAt`      | string        | ISO timestamp                   |

## Adding Documents

Edit the `DOCUMENTS` array in `app/page.tsx`:

```ts
{
  id: "your-doc-id",
  title: "Document Title",
  description: "Short description shown on the card.",
  pages: 4,
  category: "Legal",   // "Legal" | "Project" | "Compliance"
  required: true,       // true = pre-selected, can't be deselected
  content: "Full document text preview shown when expanded.",
}
```

## Deployment

```bash
# Deploy Convex backend
npm run convex:deploy

# Deploy Next.js (Vercel recommended)
npx vercel
```

Set `NEXT_PUBLIC_CONVEX_URL` in your Vercel project environment variables.
